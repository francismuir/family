⬇ Download GEDCOM (.ged) for Ancestry.co.uk
How to import into Ancestry.co.uk:
  1. Sign in to Ancestry.co.uk and click Trees → Create & Manage Trees.
  2. Click Upload a GEDCOM file at the bottom of the list.
  3. Select muir_family_tree.ged and name your tree (e.g., The Muir Family Tree).
